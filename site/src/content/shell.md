# シェルの機能

画面の縁を囲む細い**枠**と、左の**縦バー**が基本の形です。ダッシュボード・通知・ランチャーなどは、枠から**ドロワー**として伸びてきます(caelestia 風のレイアウト)。上部に横長のバーを置く `classic` レイアウトも選べます。

::img shot-hero.jpg | 枠と縦バー、ガラスのドロワー。壁紙はシェーダで描くオーロラ

## 縦バー {#bar}

- 上から OS のロゴ(`/etc/os-release` の画像、無ければ Nerd Font の OS アイコン。FreeBSD は赤いデーモンのマーク)、ワークスペース 1〜9、時計、音量・Wi-Fi・Bluetooth・バッテリー、電源。
- ワークスペースは、窓のある番号に印が付き、今の番号は光ります。クリックで移動します。
- アイコンにカーソルを乗せると**ポップアウト**が開き、音量・出力先・入力・明るさなどをその場で変えられます。
- 時計は「次の分の境目」に 1 回だけ起きて描き直します(秒表示を on にしたときだけ毎秒)。

## ダッシュボード(上・Super+A) {#dashboard}

::video dashboard | 4 つのタブ。タブの下線と中身がばねで滑ります

| タブ | 中身 |
|---|---|
| ダッシュボード | 天気(場所は設定か IP から推定)、機種・CPU・GPU 名、**自分の写真**(クリックで選ぶ)、WebAssembly のカレンダー、再生中のメディア(アルバム名つき) |
| メディア | 下の「メディア」を参照 |
| パフォーマンス | CPU・GPU・メモリ・ストレージの円グラフ。CPU と GPU は温度つき |
| ワークスペース | 1〜9 のそれぞれで**開いているアプリのアイコンと名前** |

::img shot-performance.jpg | パフォーマンス: Linux は sysfs / procfs、FreeBSD は sysctl から読みます

## メディア {#media}

::video media | 回るレコード・トーンアーム・液体のスペクトラム・1 行ずつポンと出る同期歌詞

- **レコード**: 中央のラベルは**アルバムアートが回ったもの**です。目が疲れないよう 1 周 24 秒でゆっくり回します。
- **トーンアーム**: 再生中は針が黒い盤面の**溝**に乗り、曲の進みに合わせて外周から内側へ動きます。止めると持ち上がり、レコードの外へ戻ります。
- **スペクトラム**: 再生中の音を録音して ame-shell の中で FFT し、レコードを包む液体の膜として描きます(cava は使いません)。
- **同期歌詞**: いくつかの取り寄せ先から自動で探します(プレーヤー自身の歌詞ファイル → キャッシュ → music-tui の歌詞サーバ → [LRCLIB](https://lrclib.net/) → NetEase → 酷狗(Kugou)→ 曲名だけで LRCLIB)。YouTube の「【MV】アーティスト「曲名」」や「〜 - Topic」のような書き方は、検索の前にアーティストと曲名へ整えます。今の行だけを大きく表示し、行が変わるたびに**下から弾んで**出ます。歌詞欄の上をクリックすると前の行へ、下をクリックすると次の行へ飛びます(シーク)。ホイールで前後の行を見られ、5 秒触らなければ今の行へ戻ります。
- **曲の情報**: MPRIS(D-Bus を直接)から曲名・アーティスト・**アルバム名**・長さ・再生位置・アルバムアートを受け取ります。
- **配色**: 再生中はアルバムアートの色がアクセントになります(`theme { media-accent on }`)。

> **プレーヤー側から歌詞を渡せます**: `$XDG_RUNTIME_DIR/lyrics/<MPRIS のプレーヤー名>.lrc` に、`[ti:]`・`[ar:]`・`[al:]` 付きの LRC を置くと、LRCLIB より優先して使います。曲名とアーティストが今の曲と一致するときだけ使うので、古いファイルが残っていても間違いません。ターミナルの音楽プレーヤー [music-tui-bsd](https://github.com/TatsuyaM2667/music-tui-bsd) がこの仕組みに対応しています。

## ランチャー(下・Super / Super+D) {#launcher}

::video launcher | 打つたびに Odin のあいまい検索で並び替わります

- **Super を単独で押して離す**と開きます(Super+何かのキー操作とは区別します)。
- **あいまい検索**: 単語の先頭・区切り(空白 `-` `_` `.` `/`)・camelCase の境目・連続一致を高く評価します。Odin で書いた同じ関数が、下のデモで動きます。
- **よく使う順(frecency)**: 使った回数と最近使ったかどうかで、上に来ます。
- **お気に入りの固定**: Ctrl+F か右クリック。
- **アイコン**: すべてのアイコンテーマの索引と SVG(nanosvg)に対応しています。
- `>` でアクション(ロック・再起動・アップデートなど)、`>壁紙` で壁紙を選べます。

::demo fuzzy

## 壁紙 {#wallpaper}

::video wallpaper | 壁紙ピッカー(Super+Shift+W)。選んだカードの位置から切り替わり、配色も合わせて変わります

| 種類 | 中身 |
|---|---|
| オーロラ・雨 | GPU のシェーダで描く**ライブ壁紙**。AC 電源のときは 30fps、バッテリーのときは 12fps・解像度 3/4 に自動で下げる |
| 画像 | JPEG・PNG(stb_image) |
| 動画・GIF | **libmpv** を実行時に読み込み、ハードウェア復号で GPU に直接描く。libmpv が無い・再生できない・5 秒たっても映らないときは、**ffmpeg** で再生する(VA-API で復号と縮小、だめなら CPU)。それでも無理なら理由を通知する |

- 壁紙は `~/Pictures/wallpapers` などのフォルダから自動で集めます(同じ名前は 1 つにまとめます)。
- 切り替えの演出は 4 種類(波紋・円・斜めワイプ・短冊)。`wallpaper { transition random }` で毎回変わります。

## 壁紙から配色 {#theme}

::img shot-theme-from-wallpaper.jpg | 壁紙の色から、アクセント・ガラスの色・文字色を作ります

配色は 2 段階で作ります([詳しく](#/tech-glass))。**ガラスと文字の色合い**は、Odin の `ame_dominant_color` が求める「出現数 × (0.15 + 彩度²)」がいちばん大きい色から作ります。**アクセント**は別に、鮮やかで中くらいの明るさの画素ほど重く数えた色相の分布の山を求め、それを 8 つの「アクセントとして見栄えの良い色相」(琥珀・ティール・スカイ・ブルー・ペリウィンクル・バイオレット・オーキッド・ピンク)へ 75% 寄せます。黄緑〜緑の帯と赤の帯からは完全に外します。くすんだ緑は「有効」の表示が安っぽく見え、赤はエラーの色と紛らわしいからです。**エラーは赤**と決めていて、Wi-Fi の接続失敗などでは、枠の縁が一瞬赤く光ります。

::demo color

## 通知 {#notify}

- ame-shell 自身が **D-Bus の通知サーバ**(`org.freedesktop.Notifications`)になります。mako や dunst は要りません。
- 右上にガラスのカードとして右から滑り込み、上のカードが消えると下のカードがばねで詰めます。消えるときは右へ流れて薄くなります。アクション(ボタン)・置き換え・期限に対応し、緊急の通知では枠が赤く光ります。
- すでに別の通知デーモン(mako・swaync など)が動いていれば、名前を奪わずに譲ります。
- 通知センター(Super+N)で履歴を見られます。通知停止(Do Not Disturb)も切り替えられます。

## ユーティリティ・セッション {#utilities}

- **ユーティリティ**(Super+U): Wi-Fi・Bluetooth・通知停止・スリープ防止・**録画**(wf-recorder、`~/Videos` に保存して通知。PC で鳴っている音も一緒に録る)・スクリーンショット・電源プロファイル(省電力 / バランス / 高性能)。
- **Wi-Fi・Bluetooth のパネル**: 一覧・接続・パスワード入力。外側をクリックすると閉じます。AirPods などは接続すると高音質(A2DP)の出力にし、通話用の低音質(HFP)への自動切り替えを止めます。
- **セッション**(Super+Escape): ロック・ログアウト・スリープ・再起動・電源オフ。危険な操作は 2 回押しです。FreeBSD では ConsoleKit2 で行います。

## ハンド操作 {#hand}

カメラに映った手の動きで、カーソルと窓を操作します。ユーティリティ(Super+U)の「ハンド操作」ボタンか `ame-ctl hand toggle` で切り替えます(既定はオフ。`hand { enabled on }` で起動時からオン)。

| 手の動き | 操作 |
|---|---|
| 指さす(人差し指だけ伸ばす) | カーソルが指先に付いて動く。窓のフォーカスもカーソルに付いて移る |
| 親指と人差し指でつまむ | 短くでクリック。つまんだまま動かすと、カーソルの下の窓をつかんで動かす(浮いた窓は紙のようにたわむ) |
| 開いた手を左右に払う | 隣のワークスペースへ(左へ払うと次、右へ払うと前) |
| 握りこぶしを 0.9 秒保つ | フォーカス中の窓を閉じる(赤い輪が満ちたら) |
| 開いた手を止めて 1.3 秒 | 全画面の切り替え |

操作のたびに、カーソルの位置から水の波紋が広がります。

- 手の認識は MediaPipe の手のモデル(手のひらの検出 + 関節 21 点、Apache-2.0)を使い、それを動かす**推論エンジンを Zig で書きました**(`src/hand/nn.zig`。TFLite のファイルを自分で読み、畳み込みは 4 画素 × 16 チャンネルをレジスタに置いて FMA で計算)。C++・Python・OpenCV・TensorFlow は使いません。
- 推論は別のスレッドで動き、描画を止めません。手を追っている間は関節のモデルだけ(1 回 7〜10ms)、見失ったら手のひらの検出に戻ります。
- 誤操作を防ぐため、手の形は 2 コマ続いたら確定し、閉じる・全画面は手が見えてから 0.6 秒たってから受け付けます。払った直後は全画面にしません。

## ロック画面とログイン画面 {#lock}

::img shot-lock.jpg | Super+L のロック画面

- `ext-session-lock-v1` で画面をロックし、PAM でパスワードを確かめます。iOS / iPadOS のロック画面のような作りです(日付・特大の時計・電池・ロック中に来た通知・光が流れる「解除するには…」)。
- 再生中の曲は**右下の小さなカード**(回るレコードと液体のビジュアライザー、前・再生・次)に出し、**歌詞**はダッシュボードと同じ見せ方で上に浮かべます。
- 解除すると**水の波紋**が中心から広がり、波が通り過ぎた所からデスクトップが透けて見えます。ロック中はコンポジタがデスクトップを見せないので、ロック画面の最後の絵を写した全面のオーバーレイを先に出し、それが描けてからロックを外します([詳しく](#/tech-notify-lock))。
- **FreeBSD** でも同じロック画面です。FreeBSD の pam_unix は root でないとパスワードを照合できないので、照合だけを小さな setuid の補助 `ame-auth` に任せます(swaylock が setuid で入るのと同じ考え)。
- **ログイン画面**も ame-shell 自身が描きます(greetd + `ame-greeter`)。ロック画面と同じ見た目で、真ん中の穴から壁紙が見え、ログインするとその穴を抜けてデスクトップへ入ります。greetd の無い FreeBSD では、同じ見た目の SDDM のテーマを使います。

## WebAssembly のウィジェット {#widgets}

- ダッシュボードのカレンダー・時計・システムモニタ・メディアなどは、**Zig で書いて wasm32 にビルドしたウィジェット**です。
- ame-shell の中の [wasm3](https://github.com/wasm3/wasm3)(C で書かれた小さな WebAssembly インタプリタ)で動きます。WASI は無効で、メモリは 1 MiB 固定です。外部とのやりとり(import)は `ame.action(i32, f32)` の 1 つだけです。
- ウィジェットは自分のメモリに描画命令の配列を書き、ame-shell がそれを**コピーせずに**直接読みます。
- `.wasm` を保存すると inotify で検知し、**状態を保ったまま**差し替えます(ホットリロード)。

```zig
// widgets/clock.zig(抜粋)— 分が変わると、数字がばねで下から持ち上がる
pub fn frame(dt: f32, w: f32, _: f32) bool {
    const s = &ame.store;          // 時刻・システム・メディアの値(ホストが書き込む)
    const st = &state;             // ホットリロードしても保たれる状態
    if (st.last_min != s.min) {
        if (st.last_min >= 0) {
            st.flip.x = 0;
            st.flip.target = 1;
        }
        st.last_min = s.min;
    }
    var anim = st.flip.step(dt);   // ウィジェットの中でも同じばね
    ...
    const time = ame.fmt("{d:0>2}:{d:0>2}", .{ @as(u32, @intCast(s.hour)), @as(u32, @intCast(s.min)) });
    ame.text(2, 74 + (1 - f) * 14, 58, ame.rgba(ame.mix(s.text, s.accent, 0.15), f * t), time, true, .left, 0, 8);
    ...
}
```

## そのほか {#misc}

- **端末**: ghostty(ame-shell と同じ Zig 製。無ければ foot)。半透明の夜空色で開き、最初に fastfetch を表示します。中のシェルは zsh の設定つき。
- **ファイル**(Super+E): Thunar を、端末と同じ半透明のテーマ(AmeGlass)で開きます。ほかの GTK アプリの見た目は変えません。
- **日本語入力**: fcitx5 + Mozc。Chimera などパッケージの無い環境では `sh install.sh --mozc` でソースからビルドします。
- **画面の拡大率**: 画素の細かさを見て自動で決めます(14 インチ 2880x1800 なら 1.5 など)。
- **無線のブロック解除**: Linux ではセッションの開始時に `rfkill unblock all`。
- **タッチパッド**: タップでクリック(River 0.5 の `river_libinput_config_v1`)。
- **設定**は `~/.config/ame-shell/config.ame`。**保存した瞬間に反映**されます。[設定の一覧](#/reference)
