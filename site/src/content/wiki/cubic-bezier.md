# 3 次ベジェ曲線

::infobox 3 次ベジェ曲線
英語 | Cubic Bézier curve
式 | B(t) = (1−t)³P₀ + 3(1−t)²t P₁ + 3(1−t)t² P₂ + t³P₃
アニメーションでの使い方 | CSS の cubic-bezier()、Hyprland の bezier
ame-shell | 使わない(比較の対象)

**3 次ベジェ曲線**は、4 つの点で形が決まる、なめらかな曲線です。アニメーションでは「時間の進み方」の形として使われます。

## 概要 {#overview}

CSS の `transition-timing-function: cubic-bezier(0.25, 0.1, 0.25, 1)` のように、始点(0,0)と終点(1,1)の間に 2 つの制御点を置いて、「最初はゆっくり、途中で速く、最後はゆっくり」などの動き方を決めます。横軸が時間の割合、縦軸が進み具合です。

## 仕組み {#how}

- 時間の割合 x が与えられたら、まず `B_x(t) = x` となる t を数値的に求め(ニュートン法や二分法)、その t で `B_y(t)` を計算します。
- 制御点の y が 1 を超えると、目標を行き過ぎて戻る動き(オーバーシュート)になります。Hyprland の既定の例 `0.05, 0.9, 0.1, 1.05` はこの形です。

## ame-shell での比較 {#ame}

ame-shell はベジェ曲線を使わず、[[spring|ばね]]で動かします。違いが出るのは、**動いている途中で目標が変わったとき**です。ベジェ曲線は「今の位置から、新しい曲線を 0 秒目から」始めるしかなく、その瞬間に速度が飛びます。ばねは速度を保ったまま曲がります。[アニメーション](#/animation)のデモで、両方を並べて比べられます。

## 理論と研究 {#theory}

:::research de Casteljau のアルゴリズムと、速度の不連続
ベジェ曲線は、Paul de Casteljau(シトロエン、1959)と Pierre Bézier(ルノー、1962)が独立に考案しました。de Casteljau のアルゴリズム(線形補間の繰り返し)で、数値的に安定に評価できます。

イージングとしての曲線 y = f(x) の速度は、f'(x) / 継続時間 です。途中(進み具合 p、速度 v)で目標を変えて新しい曲線を始めると、新しい速度は f'(0) × (新しい距離) / 継続時間 になり、一般に v と一致しません。速度を一致させるには、曲線の制御点を毎回計算し直す必要があり、そうすると「決めた形の曲線」という利点が失われます。
:::
