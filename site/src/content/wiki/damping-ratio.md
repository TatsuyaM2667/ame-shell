# 減衰比

::infobox 減衰比
記号 | ζ(ゼータ)
定義 | ζ = c / (2√(mk))
意味 | 1 で臨界減衰、1 未満で振動、1 を超えて過減衰
ame-shell | 各ばねの「弾み方」を決める値

**減衰比**は、[[spring|ばね-ダンパ系]]が「どれくらい弾むか」を表す、単位のない数です。

## 概要 {#overview}

- **ζ = 1**: 行き過ぎずに、いちばん速く目標に着く(臨界減衰)。
- **ζ < 1**: 目標を少し行き過ぎて戻る。小さいほどよく弾む。
- **ζ > 1**: 行き過ぎないが、ゆっくり近づく。

## ame-shell での主な値 {#ame}

| どこ | ζ | 見た目 |
|---|---|---|
| ロック画面の失敗の揺れ | 0.25 | 何度も揺れて止まる |
| 歌詞のポップ | 0.55 | よく弾む |
| 窓が開く | 0.68 | はっきりしたポップ |
| ドロワーの開閉 | 0.70 | 少し行き過ぎて戻る |
| 窓の位置 | 0.80 | わずかに行き過ぎる |
| 窓の大きさ | 0.90 | ほぼ行き過ぎない |
| 壁紙の切り替え | 1.0 | 行き過ぎない |

## 理論と研究 {#theory}

:::research 行き過ぎ量と整定時間
不足減衰(ζ < 1)の、ステップ入力に対する最大の行き過ぎ量は `M_p = exp(−πζ / √(1 − ζ²))` です。ζ = 0.7 なら約 4.6%、ζ = 0.5 なら約 16%、ζ = 0.25 なら約 44% です。

整定時間(2% 以内に収まるまで)の目安は `4 / (ζω)` です。ame-shell は応答時間(= 2π/ω)と ζ を分けて指定するので、「速さ」と「弾み方」を独立に調整できます。
:::
