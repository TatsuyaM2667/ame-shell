# dwindle レイアウト

::infobox dwindle
種類 | タイル型の窓の並べ方
考え方 | 残りの領域を長い辺で 2 等分していく
使われている所 | Hyprland(既定)、bspwm に近い
ame-shell | River 0.5 の WM の配置

**dwindle** は、窓が増えるたびに、**残りの領域を長いほうの辺で半分に分けていく**、タイル型の窓の並べ方です。窓がらせん状に小さくなっていきます(dwindle = だんだん小さくなる)。

## 概要 {#overview}

1 つ目の窓は画面全体。2 つ目が来たら、画面を左右に半分ずつ。3 つ目は、右半分(縦長)を上下に分けて…と、そのとき残っている場所の「長い辺」で分けます。窓が細長くなりすぎず、どの窓もそこそこの大きさになります。

## 仕組み {#how}

```zig
var r = area;
for (tiled[0..n], 0..) |w, i| {
    var cell = r;
    if (i + 1 < n) {
        const ratio = if (i == 0) self.ratio else 0.5;
        if (r[2] >= r[3]) { /* 横長: 左右に分ける */ … } else { /* 縦長: 上下に分ける */ … }
    }
    self.place(w, cell);
}
```

1 つ目の窓だけ比率を変えられます(Super+Ctrl+H・L)。新しい窓は、フォーカスしている窓の**次**に入るので、今見ている窓の隣に開きます([ウィンドウマネージャ](#/tech-wm))。

## 理論と研究 {#theory}

:::research 二分空間分割として
dwindle は、二分空間分割(BSP)木の特別な形で、木が片側にだけ伸びる(各ノードの片方の子が葉)ものです。一般の BSP(bspwm など)は、どの窓を分けるかを自由に選べますが、dwindle は「並び順」だけで配置が決まるので、状態が単純で、窓の入れ替えも並び順の入れ替えだけで済みます。

縦横比の観点では、「長い辺で分ける」規則により、各窓の縦横比は 1:2 から 2:1 程度に収まりやすく、細長い窓ができにくくなります。
:::
