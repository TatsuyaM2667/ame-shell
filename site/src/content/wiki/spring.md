# ばね-ダンパ系

::infobox ばね-ダンパ系
英語 | Mass–spring–damper system
運動方程式 | m·ẍ = −k(x − x*) − c·ẋ
特徴量 | 固有角振動数 ω = √(k/m)、減衰比 ζ = c / (2√(mk))
ame-shell | すべてのアニメーション(配色以外)

**ばね-ダンパ系**は、ばね(元に戻ろうとする力)と、ダンパ(動きを止めようとする抵抗)でつながったおもりの動きを表す、物理のモデルです。ame-shell のアニメーションは、すべてこのモデルで計算しています。

## 概要 {#overview}

ドアがゆっくり閉まる仕組み(ドアクローザー)や、車のサスペンションを思い浮かべてください。ばねが目標の位置に引っぱり、ダンパが勢いを殺します。抵抗が弱いと行き過ぎて何度か揺れ、強いとゆっくり近づきます。

UI のアニメーションにこのモデルを使うと、**途中で目標が変わっても、今の勢いを保ったまま新しい目標へ曲がっていく**動きになります。人の手でものを動かしたときに近い、自然な動きです。

## 仕組み {#how}

位置を x、速度を v = ẋ、目標を x* とすると、

```
加速度 a = −k·(x − x*) − c·v        (質量 m = 1)
```

ame-shell では、k と c を直接ではなく、見た目に直結する 2 つの値から決めます。

- **応答時間**(response): 1 回揺れる周期。ω = 2π / response、k = ω²。
- **[[damping-ratio|減衰比]]** ζ: c = 2ζω。

この式を、短い時間の刻みで [[symplectic|半陰的オイラー法]]で積分します([ばねとアニメーションの中核](#/tech-anim))。

## ame-shell での使われ方 {#ame}

窓の位置と大きさ、ドロワーの開閉、通知、歌詞のポップ、トーンアーム、壁紙の切り替えまで、Odin で書いた同じ関数 `ame_spring_step` で計算します。[アニメーション](#/animation)のページで、ブラウザの中で実際に動かせます。

## 理論と研究 {#theory}

:::research 解の形と固有値
方程式 `ẍ + 2ζω ẋ + ω²(x − x*) = 0` の特性方程式は `λ² + 2ζωλ + ω² = 0`、根は `λ = −ζω ± ω√(ζ² − 1)` です。

- **ζ < 1(不足減衰)**: 複素根。`x(t) − x* = e^{−ζωt}(A cos ω_d t + B sin ω_d t)`、ω_d = ω√(1 − ζ²)。行き過ぎて揺れながら収まる。行き過ぎの量は `exp(−πζ/√(1−ζ²))`。
- **ζ = 1(臨界減衰)**: 重根。`(A + Bt)e^{−ωt}`。行き過ぎずに**最も速く**収まる。
- **ζ > 1(過減衰)**: 実根 2 つ。ゆっくり近づく。

状態 (x, v) の線形系として見ると、目標の変更は「平衡点の移動」で、(x, v) は連続のままです。これが「速度が途切れない」ことの数学的な理由です。時間と曲線で決める[[easing|イージング]]は、目標が変わったときに速度が不連続になります。

UI へのばねの応用は、Apple の UIKit / SwiftUI(response と dampingFraction)、Android の Jetpack Compose(spring の stiffness と dampingRatio)、react-spring、Framer Motion などで広く使われています。
:::
