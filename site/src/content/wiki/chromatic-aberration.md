# 色収差

::infobox 色収差
英語 | Chromatic aberration
原因 | 光の波長(色)によって屈折率が違う(分散)
見え方 | 縁に虹色のずれ
ame-shell | ガラスの縁の厚み感

**色収差**は、レンズやガラスを通った光が、**色によって少しずつ違う向きに曲がる**ために、像の縁に虹色のずれが出る現象です。

## 概要 {#overview}

プリズムが白い光を虹に分けるのは、ガラスの中で、青い光ほど強く曲がるからです(分散)。安いレンズで撮った写真の、明るい物の縁が紫や緑に色づくのも同じ理由です。CG では、わざとこの効果を少し加えると、「本物のガラスやレンズを通して見ている」感じが出ます。

## 仕組み {#how}

画面の効果としては、**赤・緑・青を、少しずつずらした位置から読む**だけで作れます。

## ame-shell での使われ方 {#ame}

ガラスのシェーダは、縁の近くだけ、縁の向き([[sdf|距離場]]の勾配)に沿って、赤を 1.5 ピクセル外、青を 1.5 ピクセル内側から読みます。中心では 0 です。縁がうっすら虹色になり、ガラスに厚みがあるように見えます([ガラス・壁紙・配色](#/tech-glass))。

```glsl
vec2 ca = vec2(n.x, -n.y) * edge * 1.5 / u_output;
vec3 bg = vec3(texture(u_blur, uv + ca).r, texture(u_blur, uv).g, texture(u_blur, uv - ca).b);
```

## 理論と研究 {#theory}

:::research 分散と屈折
屈折は Snell の法則 `n₁ sin θ₁ = n₂ sin θ₂` に従い、屈折率 n は波長 λ によって変わります(例: Cauchy の近似式 `n(λ) = A + B/λ²`)。そのため、同じ入射角でも、青(短い波長)ほど大きく曲がります。

ame-shell のシェーダは物理的なレイトレースではなく、「縁の近くでは、法線の向きに読む位置をずらす」という**近似**です。ずれの量を、縁からの距離の 2 乗(`edge²`)で増やしているのは、ガラスの縁が丸く(表面の傾きが縁で急に)なっている形を表すためです。
:::
