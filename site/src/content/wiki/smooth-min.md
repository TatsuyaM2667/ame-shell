# smooth-min

::infobox smooth-min
別名 | smin、なめらかな最小値
用途 | SDF の和集合を、継ぎ目が丸くなるようにつなぐ
代表的な式 | 多項式型(Inigo Quilez)
ame-shell | 枠とドロワーの融合

**smooth-min** は、2 つの値の最小値 `min(a, b)` を、**なめらかに**したものです。[[sdf|距離場]]に使うと、2 つの形が、付け根で丸く溶け合うようにつながります。

## 概要 {#overview}

2 つの形の SDF を `min` でつなぐと、和集合(両方を合わせた形)になります。ただし、つなぎ目は角ばったままです。smooth-min は、a と b が近いところ(=2 つの形の境目の近く)だけ、値を少し小さくします。すると、つなぎ目にふくらみ(凹の丸み)ができ、粘土をくっつけたように見えます。

## 仕組み {#how}

ame-shell の式(多項式型):

```glsl
float smin(float a, float b, float k) {
    if (k <= 0.01) return min(a, b);
    float h = max(k - abs(a - b), 0.0) / k;
    return min(a, b) - h * h * k * 0.25;
}
```

- `|a − b| ≥ k` のとき、`h = 0` で、普通の `min` と同じ。
- `|a − b| < k` のとき、最大で `k/4` だけ値を小さくする。`k` が丸みの大きさ。

## ame-shell での使われ方 {#ame}

画面の縁の枠と、そこから伸びるドロワー(ダッシュボードなど)を、smooth-min でつないでいます。ドロワーが開くと、付け根に丸みができて、縁が「伸びてきた」ように見えます。

**ドロワー同士は普通の `min`** でつないでいます。全部を smooth-min で連鎖させると、近くにあるドロワー同士(右上の通知と右のサイドバーなど)が、細い橋でつながってしまったからです([枠とドロワー](#/tech-frame))。

## 理論と研究 {#theory}

:::research 連続性と、距離としての性質
多項式型の smin は、`|a−b| = k` で値と 1 階微分が連続です(C¹ 連続)。そのため、つなぎ目で法線(勾配)が飛ばず、ガラスの屈折や光の当たり方も滑らかにつながります。

`h²k/4` の補正は、`a = b` のとき最大の `k/4` になります。これは「2 つの形の境界が出会う点で、表面を k/4 だけ外に膨らませる」ことに相当します。smin の結果は正確な距離ではありませんが、距離の下界(Lipschitz 定数 ≤ 1)という性質は保たれるので、輪郭のアンチエイリアスは正しく働きます。

ほかに、指数型 `−k·log(e^{−a/k} + e^{−b/k})`(どこでも滑らかだが、遠くの値にも影響する)、3 次の多項式型(C² 連続)などがあります。多項式型は「k の範囲の外ではまったく影響しない」(局所的)ので、たくさんの形を扱う UI に向いています。
:::
