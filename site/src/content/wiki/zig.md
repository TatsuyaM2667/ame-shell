# Zig

::infobox Zig
作者 | Andrew Kelley(2016〜)
種類 | 汎用のシステムプログラミング言語
特徴 | 隠れたメモリ確保・制御の流れが無い、comptime、C との直接の相互運用
ame-shell | 本体(約 17,600 行)・ビルド・ウィジェット・このサイト(版 0.13 に固定)

**Zig** は、C の置き換えを目指した、システムプログラミング言語です。ame-shell の本体はほぼすべて Zig で書いています。

## 概要 {#overview}

C のように低いレベル(メモリ・ハードウェア)を直接扱えますが、C の落とし穴(配列の範囲外・整数のあふれ・null)を、安全検査の付いたビルドでは実行時に見つけてくれます。C のヘッダをそのまま読めるので、C のライブラリをバインディングなしで使えます。

## 特徴 {#features}

- **隠れたメモリ確保が無い**: メモリを確保する関数は、必ずアロケータを引数に取ります。
- **comptime**: コンパイル時にコードを実行できます。型も値として扱えるので、ジェネリクスもこれで書きます。
- **エラーは値**: `!T` 型と `try`。例外はありません。
- **`@cImport`**: C のヘッダを読み、Zig から呼べるようにします([[translate-c]])。
- **ビルドシステム**: `build.zig`(Zig で書く)。C / C++ のコードもコンパイルできます。
- **[[cross-compilation|クロスコンパイル]]**: 1 つのコンパイラで、多くの OS と CPU 向けに作れます。

## ame-shell での使われ方 {#ame}

本体・ウィンドウマネージャ・WebAssembly のウィジェット・ビルド・このサイトの描画エンジンを Zig で書いています。版は 0.13 に固定しています(Zig はまだ 1.0 前で、版によって言語や標準ライブラリが変わるため)([言語とツールチェイン](#/tech-lang))。
