# FreeBSD 移植記: 番号 286 の SIGSYS から、タッチパッドまで

ame-shell は FreeBSD でも動きます。ただ、そこに至るまでには、Linux では起きない問題がいくつもありました。

## 実機が無くても、ビルドだけは毎回確かめる {#cross}

作者の手元の機械は Chimera Linux です。そこで、FreeBSD の `base.txz` とパッケージを展開して **sysroot** を作り、Linux の上で FreeBSD 向けにビルドしてリンクまで確かめる仕組みを作りました([[cross-compilation]])。epoll・timerfd・inotify は、libepoll-shim と libinotify で補います([[kqueue]])。

## 起動直後の SIGSYS {#sigsys}

それでも、実機で試すと、起動してすぐに **SIGSYS** で落ちました。「その OS に無いシステムコールを呼んだ」というシグナルです([[sigsys]])。

原因は、タイマーの設定でした。[[musl]] の `struct timespec` が Zig の [[translate-c]] で扱えなかったため、Linux 版では Zig の `std.os.linux.timerfd_settime` を使っていました。これは **Linux の番号 286 を直接**呼びます。そのコードが FreeBSD 向けにもコンパイルされ、FreeBSD には 286 番が無いので落ちたのです。コンパイルもリンクも通るのに、実行すると落ちる、という種類の間違いでした。

直したあと、**FreeBSD 向けのバイナリを逆アセンブルし、`syscall` 命令と `os.linux.*` の記号が 0 個であることを毎回確かめる**ようにしました。

原因が分かったのは、落ちたときに ASCII でシグナル名をログに出すハンドラを入れていたからです(TTY のコンソールでは日本語が出ないことがある)。

## そのほかの違い {#others}

| 症状 | 原因 |
|---|---|
| ディスクの容量が読めない | `struct statvfs` のメンバーの並びが Linux と FreeBSD で違う |
| Super キーのタップが効かない | `ioctl` の番号の作り方(読み出しのビット)と、第 2 引数の型が違う([[ioctl]]) |
| ロックできない | FreeBSD の pam_unix は root でないとパスワードを照合できない → setuid の swaylock に任せる([[setuid]]) |
| 動画の壁紙が出ない | libmpv が使えない環境 → ffmpeg で再生する経路を追加([[va-api]]) |
| タッチパッドが動かない | I2C のタッチパッドのドライバ(ig4・iichid・hmt)が既定で読み込まれない |
| 録画できない | wf-recorder を入れていなかった。黙って失敗していたので、通知するように |

## 「黙って失敗しない」 {#loud}

最後の 2 つ(動画の壁紙・録画)は、どちらも**失敗しても何も言わずに元に戻っていた**ことが問題でした。動画を選んでも壁紙が変わらない、録画ボタンを押しても何も録れていない。ユーザーには、何が起きているのか分かりません。

今は、失敗したら画面の縁が赤く光り、理由を通知で出します([エラーの光](#/tech-glass))。「赤はエラーのときだけ」と決めているので、赤く光ったら必ず何かが失敗しています。
