# 性能

「アニメーションが多い = 重い」とは限りません。ame-shell は、**動いているときだけ描き、止まったら完全に眠る**ように作っています。

::stats
92〜160 ms | 起動 → 最初のバーのフレーム
0.0〜0.1 % | 待機時の CPU(壁紙静止)
1.0〜1.1 % | 待機時の CPU(ライブ壁紙 30〜60fps)
0.8〜1.1 ms | 1 回の描画の CPU 時間(平均)
9.9 ms | 1 回の描画の最大(初めて開く操作を含む)
69〜75 MB | メモリ(PSS)

## 計測の条件 {#env}

- Ryzen 7 7735HS / Radeon 680M / Mesa 26.2 / `zig build -Doptimize=ReleaseFast`
- 入れ子(ヘッドレス)の River の中、1280x720
- CPU は `/proc/<pid>/stat` の utime + stime の 10 秒間の差分、メモリは `/proc/<pid>/smaps_rollup`
- 描画時間は ame-shell 内蔵のフレーム統計(`ame-ctl stats`)と、遅いフレームの内訳(`AME_DEBUG_FRAMES=8`)

## 目標と結果 {#budget}

| 項目 | 目標 | 実測 | 判定 |
|---|---|---|---|
| 待機時 CPU(壁紙静止 `animate off`) | < 0.5 % | 0.0〜0.1 %(10 秒で 0〜1 tick) | ✓ |
| 待機時 CPU(オーロラ 30fps) | < 2 % | 1.1 % | ✓ |
| 待機時 CPU(雨 60fps) | < 2 % | 1.0 % | ✓ |
| 起動 → バー表示 | < 300 ms | 92〜160 ms | ✓ |
| 1 回の描画(平均) | < 16.6 ms(60Hz) | 0.8〜1.1 ms | ✓ |
| 1 回の描画(最大、初めて開く操作を含む) | < 16.6 ms | 9.9 ms | ✓ |
| メモリ PSS | < 80 MB | 69〜75 MB | ✓ |
| メモリ 私有(anon) | < 60 MB | 57〜60 MB | △ ぎりぎり |
| 動画壁紙(720p、libmpv) | — | CPU 約 5 %・メモリ +130 MB | 動画を選んだときだけ |

> **RSS(126〜137 MB)ではなく PSS で見ている理由**: GPU ドライバ(Mesa)は起動の時点で LLVM の共有ライブラリ(約 45 MB)を読み込みます。これはほかの GL アプリと共有される分なので、システム全体での実際の負担を表すのは PSS(共有分を人数で割ったもの)です。ame-shell が起動直後、EGL を初期化する前の時点で、すでに RSS は 51 MB あります。

## なぜ軽いのか {#why}

::cards
😴 | ポーリングしない | 「16 ms ごとに起きて確認する」タイマーがありません。描画は `wl_surface.frame`(コンポジタからの次の画面更新の合図)に合わせ、止まれば何もしません。
📬 | すべてを 1 つの epoll で待つ | Wayland・D-Bus・設定ファイルの変更(inotify)・音量(`pactl subscribe`)・曲(`playerctl --follow`)・ame-ctl は、すべて fd として 1 つの epoll に入れます。変化があったときだけ起きます。
⏰ | タイマーは「次に変わる時刻」だけ | 時計は次の分の境目にだけ起きます。バッテリーなどは 20 秒ごと、ダッシュボードの 1 秒更新は開いている間だけです。
🧵 | 描画は 1 回の命令に | どの部品も四角形の配列に積んで、まとめて 1 回の描画命令で GPU に送ります。
🔤 | 文字は先に用意 | よく使うグリフはアイドル時間に先読みします。初めてランチャーを開いても、文字の生成で待ちません。
🔋 | 電池を見て落とす | バッテリーのときはライブ壁紙を 12fps・解像度 3/4 に下げます。

## 遅かったところと直し方 {#fixes}

| 現象 | 原因 | 対策 | 結果 |
|---|---|---|---|
| ランチャーを初めて開くと 525 ms | アウトラインから SDF を作るのが 1 字 6.6 ms × 約 100 字 | 作り方を変えて 2.2 ms/字 + アイドル時間に先読み | 開くときの生成 0 字 |
| ランチャーで 92 ms | 巨大なアイコン画像のデコード | 別スレッドで 64x64 に縮小 | 描画スレッドから消えた |
| ダッシュボードを初めて開くと 19 ms | まだ作っていないアイコンのグリフ 9 字 | 先読みに UI のアイコンを追加 | 9.9 ms 以下 |
| グリフ置き場の拡張時に一瞬止まる | 拡張のたびにキャッシュを全部消していた | 最初から 2048² | 拡張しない |

## 自分で測る {#measure}

```sh
zig build -Doptimize=ReleaseFast
ame-ctl stats                 # 稼働時間・CPU 時間・RSS・フレーム数・平均/最大の描画時間
AME_DEBUG_FRAMES=8 ame-shell  # 8 ms を超えたフレームの内訳を出す
AME_DEBUG_MEM=1 ame-shell     # 起動の段階ごとのメモリ
```

> ほかの環境(Hyprland・GNOME など)の数字は、同じ条件で測っていないので載せていません。比べる場合は、同じ機械で上の方法で測ってください。
